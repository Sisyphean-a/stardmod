# 钓鱼条成长领域上下文

该上下文负责把玩家的有效鱼类捕获记录映射为原版钓鱼小游戏的额外钓鱼条高度，并在游戏内提供可读的统计反馈。

## 通用语言

**有效鱼类**：`fishCaught` 中经物品数据识别为鱼的条目；当排除选项开启时，不包含藻类和凝胶。

**钓鱼条基础高度**：`BobberBar` 构造时由游戏本体、玩家技能和装备等因素计算出的高度，未包含本包奖励。

**成长奖励**：按有效鱼类总捕获数和 `FishPerPixel` 的整数除法计算出的额外像素。

**最终钓鱼条高度**：基础高度加成长奖励，再应用可选的 `MaxBarHeight` 上限。

**钓鱼统计 HUD**：玩家手持鱼竿时显示有效鱼类数量、基础高度、成长奖励和最终高度的游戏内信息面板。

## 稳定规则

- 有效鱼类统计读取每个 `fishCaught` 条目的 `stats[0]`，使用物品数据的 `ObjectType` 包含 `Fish` 或 `Category == -4` 作为鱼类判定。
- 开启排除选项时，`(O)152`、`(O)153`、`(O)157`、`(O)812`、`(O)851` 和 `(O)852` 不计入统计；前 3 个是藻类/海草，后 3 个是凝胶。
- 每累计 `FishPerPixel` 条有效鱼增加 1 像素，余数不产生部分像素；`FishPerPixel` 不大于 0 时不产生奖励。
- `MaxBarHeight` 大于 0 时限制最终高度，设置为 0 表示无限制；安装后已有捕获记录会立即参与下一次钓鱼条计算。
- 宝藏判定使用应用本包奖励前的高度，只排除本包实际加入的像素，不覆盖游戏本体或其他 mod 的高度调整。
- HUD 只有在功能和 HUD 均启用、且玩家手持 `FishingRod` 时显示；打开配置菜单或直接修改 `config.json` 可调整增长、上限、显示和位置设置。
- Generic Mod Config Menu 为可选依赖；没有它时不影响主体功能，但不能使用游戏内配置入口。
- 统计与高度修改只发生在客户端当前玩家的钓鱼流程中，不新增存档数据，不提供多人同步协议。
