# 快捷键查看器领域上下文

快捷键查看器帮助玩家在游戏内查看本体与已加载模组的快捷键，并发现潜在按键冲突。

## 通用语言

**快捷键查看器**：通过独立快捷键打开的游戏内面板，展示本体按键、模组按键、来源和潜在冲突。

**本体快捷键**：星露谷原版 `Options` 中当前配置的输入按钮。

**GMCM 注册项**：模组通过 Generic Mod Config Menu 注册的 `SButton` 或 `KeybindList` 类型配置项，能提供较准确的功能名称。

**配置推测项**：从已加载模组 `config.json` 中按字段名和键值格式识别出的疑似快捷键；它用于补足未注册 GMCM 的模组，但准确性低于 GMCM 注册项。

**潜在冲突**：同一个按键组合被两个或更多不同功能使用；它代表需要玩家检查的风险，不表示这些功能在所有场景下一定冲突。

## 稳定规则

- 打开快捷键默认为 `OemQuestion`，即 `?` 所在按键，并可配置。
- 面板只在没有其他活动菜单、事件或对话时打开；已打开时再次按打开键关闭面板。
- 快捷键来源分为游戏本体、GMCM 注册项和配置推测项；展示时必须保留来源。
- 默认面板只展示键鼠按键；手柄按键不进入默认列表和冲突统计。
- GMCM 注册项优先于同字段的配置推测项。
- 配置推测扫描必须过滤疑似 API key、token、密码、凭证、私钥或认证密钥字段，避免把敏感内容显示到面板。
- 冲突标记只基于收集到的当前配置做静态分组，不替玩家断言运行时一定冲突。
