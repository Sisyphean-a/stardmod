# 马匹跨地图自动寻路

## 目的地

玩家骑马时，屏幕右下角出现入口按钮；点击后打开主要店铺选择弹窗。选择目的地后，玩家保持骑乘，由马匹和玩家作为整体沿原版普通室外步行出口自动移动，跨地图到达店铺入口外的安全位置并停车，不进入室内。

首版固定支持 11 个目的地：皮埃尔杂货店、乔家超市、铁匠铺、星露谷酒吧、木匠店、哈维诊所、博物馆/图书馆、威利鱼店、玛妮牧场、冒险家公会、社区中心。

## 非目标

- 马进入室内或跟随玩家进入店铺。
- 使用公交车、矿车、图腾、船、洞穴或其他非普通步行传送。
- 玩家自定义目的地、任意 NPC 目标或动态移动地点。
- 改变既有下马后跟随会话、跟随距离、马匹动画、马棚取消规则和原有普通出口跟随逻辑。
- 首版支持旅行货车、沙漠绿洲、巫师塔等不稳定或不属于普通步行网络的地点。

## 约束

- 功能继续属于独立包 `packages/HorseFollower`，不并入 Toolbox。
- 自动导航只在玩家实际骑乘马匹且当前世界状态允许时可启动；不能把骑乘状态转换成下马跟随状态。
- 目的地必须映射为固定室外地图、店铺入口和入口外安全停车点；最终停车点不能直接堵住门口，约在门口外 2 格，并根据碰撞动态选择最近可站位置。
- 跨地图只能复用或扩展原版普通 `Warp` 网络；路线需要预先计算/内置可复现的地图出口决策，不能依赖实时全图搜索到不可控的成本。
- 玩家主动按方向键时取消自动导航并把控制权交还玩家；保持骑乘。菜单打开时暂停，关闭后继续。
- 没有可达普通步行路线、目标点不可站或中途迁移失败时必须显式停止并记录原因，不能静默假装到达。
- 现有跟随状态机、路径搜索、出口识别和跨图跟随行为必须保持可验证的行为契约。

## 完成判断

- [x] 11 个固定店铺目的地在当前游戏版本中有明确的地图与入口锚点；运行时用真实马碰撞框和门口距离筛选停车点。
- [x] 从支持的室外地图到每个目的地建立普通 Warp 出口图，按出口路径规划；碰撞失败会阻塞边并重新规划，地图/路线状态不持久化。
- [x] 骑马时右下角按钮按世界、骑乘、地图和菜单状态显示；弹窗列出 11 个目的地，社区中心未开放时置灰。
- [x] 自动导航通过独立玩家 controller 保持骑乘，支持菜单暂停、方向键取消、无路/异常 Warp/下马失败，并不进入原有下马跟随流程。
- [x] 到达目标地图后用真实马碰撞框和 A* 选择入口外安全点停车，不进入室内、不堵门。
- [x] 原有下马跟随代码路径保持独立；新增逻辑使用 `[HorseFollower]` Trace 日志，独立审查无 P0-P2 阻塞。
- [x] 单包和整仓构建均为 0 警告、0 错误；最新 DLL/manifest 已安装到 `Mods/HorseFollower`，原有 config 保留。

- 目的地与领域边界 -> 已确认事实：固定 11 个主要店铺及其室外入口锚点；决策 [社区中心未解锁时的目的地状态](decisions/08-community-center-availability.md)
- 地图与跨图路线 -> 已确认事实：从普通 `Warp` 构建出口图，并按局部路径长度加权规划；决策 [跨图路线模型](decisions/02-route-model.md)
- 骑乘自动驾驶状态 -> 已确认事实：独立控制 `Farmer.controller`，保持骑乘；方向键取消，菜单暂停，异常 Warp/下马失败；决策 [自动驾驶状态机](decisions/03-riding-state.md)
- 右下角按钮与弹窗 -> 已确认并实现：`RenderedHud` + `IClickableMenu`，决策 [入口按钮与店铺弹窗](decisions/04-ui-entry.md)
- 与现有跟随逻辑的边界 -> 已确认事实：骑乘导航独立控制玩家，现有下马跟随保持不变；决策 [跟随与自动导航边界](decisions/05-follow-boundary.md)
- 游戏版本/API事实 -> 已确认事实：游戏/SMAPI 版本、普通 Warp 解析、骑乘换图和 HUD/菜单输入 API；决策 [游戏地图与 API 证据](decisions/06-game-facts.md)
- 验证与部署 -> 已完成构建、独立审查和安装；游戏内手动驾驶仍是残余风险，决策 [测试与安装验证](decisions/07-verification.md)

## 迄今决定

- [首版目的地范围](decisions/00-destination-scope.md) - 固定 11 个主要店铺，不做自定义或任意室内目标。
- [跨图传送范围](decisions/00-warp-scope.md) - 只使用原版普通室外步行出口。
- [骑乘与中断行为](decisions/00-riding-behavior.md) - 保持骑乘；方向键取消；菜单暂停。
- [室外安全停车](decisions/00-outdoor-parking.md) - 到店铺入口外约 2 格的可站点停车，不进入室内、不堵门。
- [店铺入口与安全停车点](decisions/01-destination-anchors.md) - 11 个目的地使用固定室外入口锚点；停车至少离门洞 2 格，并用真实碰撞与 A* 验证。
- [跟随与自动导航边界](decisions/05-follow-boundary.md) - 骑乘导航独立控制玩家和室外路线；现有下马跟随不接管骑乘马匹。
- [游戏地图与 API 证据](decisions/06-game-facts.md) - 当前版本只把地图 `Warp` 作为普通跨图边；HUD 用 `RenderedHud`，弹窗用 `IClickableMenu`。
- [跨图路线模型](decisions/02-route-model.md) - 从普通 `Warp` 建有向出口图，按实际局部路线长度用 Dijkstra 选择出口序列，并缓存局部路径。
- [自动驾驶状态机](decisions/03-riding-state.md) - 自动控制 `Farmer.controller`，菜单暂停，方向键取消，计划外 Warp/下马显式失败，并与下马跟随互斥。
- [入口按钮与店铺弹窗](decisions/04-ui-entry.md) - HUD 只在骑马室外无菜单时显示；弹窗支持鼠标、键盘和手柄，社区中心按存档条件置灰。
- [社区中心未解锁时的目的地状态](decisions/08-community-center-availability.md) - 未解锁时仍显示但置灰并标注“尚未开放”，不启动导航。
- [测试与安装验证](decisions/07-verification.md) - 构建、静态检查、安装和独立审查已完成；真实存档操作仍待用户实机观察。

## 打开决策项

无。

## 迷雾

- 游戏内真实存档的骑马、跨图、菜单暂停、方向键取消和最终停车尚未在本环境自动执行；这是当前唯一主要残余风险。
- 地图 Mod 或动态物体造成的运行时碰撞变化会通过当前 segment 失败和 Trace 日志暴露，并重新规划或显式失败；没有持久化旧路线缓存。
- 仓库没有现成游戏自动化测试工程，验证以本地地图/程序集调查、静态检查、构建、安装和独立审查为主。

## 范围外

- 不把自动导航拆成新的独立 SMAPI 包：当前包边界已有明确独立身份，需求是其能力扩展。
- 不支持自定义坐标、任意室内 NPC、非普通传送和旅行货车等首版范围外目标。
